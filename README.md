# 📚 Catalogo_Libros

🔗 [Ver el proyecto en vivo](https://jimenaturcios448.github.io/Catalogo_Libros/)

Catálogo interactivo de libros clásicos y bestsellers, con filtro por género. Proyecto de portafolio construido con HTML, CSS y JavaScript puro (sin frameworks).

## Tecnologías usadas

- **HTML5** — estructura de la página
- **CSS3** — diseño responsivo, animaciones y efectos hover
- **JavaScript** — renderizado dinámico de tarjetas y lógica de filtrado
- **Visual Studio Code** — desarrollo
- **Git / GitHub** — control de versiones

## Características

- Catálogo de 9 libros reales (clásicos, fantasía y misterio)
- Portadas reales obtenidas de Open Library
- Filtro interactivo por género, sin recargar la página
- Animaciones al cargar las tarjetas y efectos hover
- Diseño responsivo (se adapta a distintos tamaños de pantalla)

## Estructura del proyecto

```
Catalogo_Libros/
├── css/
│ └── estilos.css
├── js/
│ ├── libros.js # Datos de los libros
│ └── main.js # Lógica de renderizado y filtros
├── imagenes/
├── index.html
└── README.md
```

## Cómo verlo

1. Clona el repositorio
2. Abre `index.html` en tu navegador (o usa la extensión "Live Server" en VS Code)
