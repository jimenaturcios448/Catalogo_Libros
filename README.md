# 📚 Catálogo de Libros

Aplicación web interactiva para explorar y buscar libros por título, autor y género.

🔗 [**Ver el proyecto en vivo**](https://jimenaturcios448.github.io/Catalogo_Libros/)

---

## ✨ Características

- 📚 Catálogo de libros organizado por géneros.
- 🔎 Búsqueda por título o autor.
- 🏷️ Filtros por género.
- 📖 Portadas de libros mediante Open Library Covers.
- ℹ️ Ventana modal con información detallada de cada libro.
- 📱 Diseño responsive para computadora, tablet y dispositivos móviles.
- ✨ Animaciones y efectos visuales.
- 🎨 Interfaz con diseño moderno y paleta de colores inspirada en una biblioteca clásica.
- 🛡️ Imagen de respaldo cuando una portada no está disponible.
- ⚡ Interfaz completamente desarrollada con tecnologías web del lado del cliente.

---

## 🛠️ Tecnologías utilizadas

- **HTML5** — estructura de la aplicación.
- **CSS3** — diseño, responsive design, animaciones y efectos visuales.
- **JavaScript** — lógica, filtros, búsqueda y ventanas modales.
- **Open Library Covers API** — obtención de las portadas.
- **Git** — control de versiones.
- **GitHub Pages** — publicación del proyecto.

## 🔎 Funcionalidades principales

### 🔍 Búsqueda

El usuario puede buscar libros escribiendo el nombre del libro o del autor.

La búsqueda funciona de manera dinámica y no requiere recargar la página.

También puede combinarse con los filtros de género para obtener resultados más específicos.

### 🏷️ Filtros por género

Los libros pueden filtrarse por:

- Todos
- Clásicos
- Fantasía
- Misterio

Los filtros se aplican dinámicamente sobre el catálogo.

### 📖 Detalles del libro

Cada tarjeta incluye un botón **"Ver detalles"** que abre una ventana modal con información adicional del libro:

- Portada
- Título
- Autor
- Año de publicación
- Género
- Descripción

La ventana puede cerrarse mediante el botón de cierre o haciendo clic fuera del contenido.

### 📱 Diseño responsive

La interfaz se adapta a diferentes tamaños de pantalla para facilitar su uso en:

- Computadoras
- Tablets
- Dispositivos móviles

### ✨ Animaciones y efectos

El proyecto incorpora diferentes efectos visuales para mejorar la experiencia de usuario:

- Animaciones al cargar las tarjetas.
- Efectos `hover`.
- Transiciones en botones.
- Animación de apertura del modal.
- Efectos visuales en las portadas.

### 🛡️ Sistema de respaldo para portadas

Cuando una portada no puede cargarse correctamente, el catálogo muestra un icono de respaldo para evitar que la tarjeta quede visualmente incompleta.

## 🚀 Cómo ejecutar el proyecto

El proyecto no requiere instalación de dependencias externas.

### Opción 1 — Abrir directamente

Descarga o clona el repositorio y abre:

```text
index.html
```

en un navegador web.

### Opción 2 — Visual Studio Code

1. Clona el repositorio.
2. Abre la carpeta `Catalogo_Libros` en Visual Studio Code.
3. Abre el archivo `index.html`.
4. Ejecuta el proyecto utilizando un servidor local, por ejemplo **Live Server**.
